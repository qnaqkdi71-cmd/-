# 세일즈 상세페이지 카피 프레임워크

## 전체 흐름 (감정 → 논리 → 행동)

```
후킹    hero          → 3초 안에 관심 캡처 + 계속 읽게
공감    pain          → "이거 내 얘기다"
문제    problem       → 실패 원인 이해 → 해결 기대
변화    story         → Before→After 변화 확신
해결    solution      → 제품 정체성 명확히
방식    how_it_works  → 쉬워 보이게 + 신뢰
증거    social_proof  → 숫자·후기로 신뢰 최대화
권위    authority     → 제작자/브랜드 신뢰
혜택    benefits      → 가치 극대화(+보너스)
안심    risk_removal  → 환불/보장으로 장벽 제거
대비    comparison    → 있으면/없으면 선택 압박
필터    target_filter → 적합한 고객만 남기기
행동    final_cta     → 가격·긴급성·행동 유도
```

## 섹션별 카피 목표·구성

- **hero**: 핵심 혜택+결과 헤드라인, 타겟+방법 서브, 긴급성 배지.
- **pain**: 공감 질문 + 구체적 고통 3~4개 + 감정적 마무리.
- **problem**: "당신 탓이 아니다" 반전 + 진짜 원인 3개 + 관점 전환.
- **story**: Before(과거 고통) → After(변화 후) + 증거.
- **solution**: 소개 문구 + 제품명 + 한 줄 정의 + 타겟 적합성.
- **how_it_works**: 3~4단계 프로세스(각 단계 제목+설명).
- **social_proof**: 대표 숫자 + 실제 후기 3~5개(별점·이름·결과).
- **authority**: 제작자/브랜드 이력·실적·자격 + 진정성.
- **benefits**: 핵심 혜택 리스트 + 보너스(가치 표기) + 총 가치.
- **risk_removal**: 환불/보장 정책 + FAQ 2~3개.
- **comparison**: 있으면(With) vs 없으면(Without) + 선택 질문.
- **target_filter**: 추천 대상 vs 비추천 대상.
- **final_cta**: 마지막 헤드라인 + 가격(정가/할인) + 긴급성 + 마무리.

## 예시 (hero)
```
headline: "광고비 50% 줄이고 매출 2배 올리는 AI 마케팅"
subheadline: "스마트스토어 셀러를 위한 24시간 자동 최적화"
urgency(eyebrow): "선착순 100명 50% 할인"
```

## 카피 원칙
1. **자연스러운 구어체** — 번역투 금지.
2. **감정 → 논리** — 먼저 공감, 그 다음 설명.
3. **구체적 숫자** — "많은" 대신 "143명".
4. **2인칭** — "당신/여러분".
5. **짧은 문장** — 한 문장 20자 내외.
6. research의 objections를 선제 해소. 과장·허위 금지.

출력 형식·필드 매핑은 detail-page-blueprint의 copy_output.json 규격을 따른다.
