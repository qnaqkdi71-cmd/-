# 전문직 상세페이지 만들기

**직업 이름만 입력하면**, 문의를 부르는 **전문직 상세페이지**가 바로 완성되는 웹 도구입니다.
코딩 지식이 전혀 없어도 사용할 수 있습니다. 화면에서 미리 본 그대로 **HTML 파일 하나로 저장**해
바로 쓰거나, 홈페이지·블로그·광고 랜딩페이지로 올릴 수 있습니다.

## 이렇게 동작해요

1. **직업을 입력합니다.** (예: 변호사, 세무사, 인테리어, 심리상담…)
   - 목록에 있는 직업은 그 분야에 딱 맞는 문구가 자동으로 채워집니다.
   - 목록에 없는 직업을 넣어도, 그 직업 이름에 맞춰 자연스러운 페이지가 만들어집니다.
2. **기본 정보(선택)를 채웁니다.** 상호명·지역·경력·연락처·강점.
3. **오른쪽 미리보기**로 완성된 페이지를 실시간으로 확인합니다.
4. **[페이지 저장]** 을 누르면 `직업-상세페이지.html` 파일이 다운로드됩니다.

## 완성되는 페이지 구성 (문의 유도형)

- **히어로** — 후킹 헤드라인 + 무료 상담 버튼
- **이런 고민 있으시죠?** — 고객의 걱정을 대신 짚어주는 체크리스트
- **이렇게 도와드립니다** — 제공 서비스
- **왜 저희를 선택해야 할까요?** — 강점 (직접 입력한 강점 반영)
- **진행 절차** — 문의부터 마무리까지 4단계
- **고객 후기** — 별점 후기 (예시, 실제 후기로 교체 가능)
- **자주 묻는 질문** — 접었다 펴지는 FAQ
- **문의 CTA** — 전화·카카오톡 상담 버튼 + 화면 하단 고정 바

전화번호와 카카오톡 링크를 입력하면 버튼이 **실제로 연결**됩니다.

## 실행 방법

```bash
npm install
npm run dev      # http://localhost:3000 접속
```

배포는 Vercel 등에 그대로 올리면 됩니다.

## 폴더 구조

```
app/
  page.tsx              # 입력 화면 + 실시간 미리보기 (사용자가 쓰는 화면)
  layout.tsx, globals.css
lib/detail/
  types.ts              # 상세페이지 데이터 구조
  library.ts            # 직업별 맞춤 문구 + 아무 직업이나 채우는 생성기
  renderHtml.ts         # 최종 상세페이지 HTML 렌더러 (미리보기·저장 공용)
```

미리보기와 저장 파일이 **똑같은 렌더러**를 쓰기 때문에, 화면에서 본 그대로가 파일로 저장됩니다.

> 후기·통계 숫자는 예시입니다. 실제 후기와 수치로 바꿔서 사용하세요.
